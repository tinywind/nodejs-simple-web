# node.js + react.js

## Development

Use Node.js ^22.22.2, ^24.15.0, or >=26.0.0. Install the locked dependencies with `npm ci`.

- `npm start` starts the Vite development server.
- `npm test` runs the route, Redux, ref, contact editing and prop validation regression tests.
- `npm run build` creates the production files in `build/`.
- `npm run preview` serves the production build locally.

Vite replaces the deprecated Create React App toolchain. The checked-in Vite configuration retains the existing homepage asset path. React Router APIs now come from the unified `react-router` package.
